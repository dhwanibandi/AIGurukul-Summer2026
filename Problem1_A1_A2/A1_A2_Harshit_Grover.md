# AI Verifiable Output — Autocad 2D Drawing Generation and Verification

## Problem Statement

The goal was to use two AI agents — one to generate code and one to verify it — in a feedback loop. A1 generates Python code (using `ezdxf`) that produces a `.dxf` layout for a given property plot. A2 verifies the output against geometric constraints and flags any errors. A1 then uses A2's feedback to fix the code. This loop continues until A2 gives a full pass. The objective is to maximize the buildable area within the plot while satisfying all SBC setback rules.

**Agent roles:**
- **A1 (ChatGPT):** Acts as an expert architectural CAD drafter and Python developer. Generates the ezdxf code, traces the property boundary, applies setbacks, and outputs the building footprint that maximizes buildable area.

- **A2 (Gemini):** Acts as a geometry verifier. In Approach 1, it logically parses A1's Python code using its own reasoning capabilities. In Approach 2, it generates a deterministic Python Z3 solver to verify the generated `.dxf` file mathematically.

**Plot (irregular polygon, all dimensions in feet):**

| Direction | Length | To |
|---|---|---|
| — | — | (0, 0) |
| North | 76 ft | (0, 76) |
| East | 75 ft | (75, 76) |
| North | 4 ft | (75, 80) |
| East | 5 ft | (80, 80) |
| South | 80 ft | (80, 0) |
| West | 5 ft | (75, 0) |
| South | 8 ft | (75, -8) |
| West | 40 ft | (35, -8) |
| North | 8 ft | (35, 0) |
| West | 35 ft | (0, 0) |

**Physical constraints:**
- Entry is on the 40ft south-facing wall between (35, −8) and (75, −8), to be marked in the drawing.
- Existing tree is at center (77.5, 78), radius 1.5ft — cannot be removed or built over.

**SBC setbacks:**
- Front: 20ft inward from the south entry wall
- Rear: 25ft inward from the north wall
- Sides: 5ft inward from all remaining walls

**Output required:** Python/ezdxf code to generate .dxf file.

## Approaches

### Approach 1: Direct LLM Verification
A1 was given the full plot data and constraints in the prompt. Its output was passed directly to A2. A2 used its own reasoning capabilities to mathematically simulate and verify the coordinate geometry. If A2 returned any FAIL, that feedback was forwarded back to A1 to fix and regenerate. The loop ran until A2 gave a full PASS on all 5 constraints.

### Approach 2: Z3 Solver Verification (Code Generation)
Instead of relying on A2's internal text-based reasoning to evaluate Python code, A2 was tasked with generating a deterministic Z3 Solver script in Python. This solver directly parses the final `layout.dxf` file generated by A1. The script uses Z3 constraint solving to verify the validity of the geometry (Constraints 1-4) and check for mathematically maximized area optimality (Constraint 5). The terminal output of this script is then fed back to A1 for iterations.

### A2 Output: Generated Z3 Solver Script

```python
import z3
import ezdxf
import sys
import math

# =========================================================
# HELPER GEOMETRY FUNCTIONS
# =========================================================
def calculate_polygon_area(vertices):
    """Calculates the area of a polygon using the Shoelace formula."""
    if len(vertices) < 3: return 0.0
    n = len(vertices)
    area = 0.0
    for i in range(n):
        j = (i + 1) % n
        area += vertices[i][0] * vertices[j][1] - vertices[j][0] * vertices[i][1]
    return abs(area) / 2.0

def extract_dxf_data(filepath):
    """Parses DXF and extracts the Boundary and Footprint polygons."""
    try:
        doc = ezdxf.readfile(filepath)
        msp = doc.modelspace()
    except Exception as e:
        print(f"Error reading DXF: {e}")
        sys.exit(1)

    polygons = []
    for entity in msp:
        if entity.dxftype() == 'LWPOLYLINE':
            points = [(p[0], p[1]) for p in entity.get_points(format='xy')]
            if len(points) > 1 and math.isclose(points[0][0], points[-1][0], abs_tol=0.1) and math.isclose(points[0][1], points[-1][1], abs_tol=0.1):
                points.pop()
            if points:
                polygons.append(points)

    if not polygons:
        return [], []

    polygons.sort(key=calculate_polygon_area, reverse=True)
    boundary_coords = polygons[0] if len(polygons) > 0 else []
    footprint_coords = polygons[1] if len(polygons) > 1 else []
    
    return boundary_coords, footprint_coords


# =========================================================
# CORE Z3 VERIFICATION ENGINE
# =========================================================
def run_z3_verification(dxf_boundary_coords, dxf_footprint_coords):
    solver = z3.Solver()
    opt = z3.Optimize()
    
    x, y = z3.Reals('x y')
    
    # 1. Z3 Mathematical Setback Half-Planes (The Legal Zone)
    p_west, p_east, p_north = 0, 80, 76
    p_south_main, p_south_entry, entry_div = 0, -8, 35
    
    z3_west_setback  = (x >= p_west + 5)
    z3_east_setback  = (x <= p_east - 5)
    z3_rear_setback  = (y <= p_north - 25)
    z3_front_setback = z3.If(x > entry_div, y >= p_south_entry + 20, y >= p_south_main + 5)
    
    legal_zone = z3.And(z3_west_setback, z3_east_setback, z3_rear_setback, z3_front_setback)

    # 2. Z3 Max Area Mathematical Optimization
    fp_min_x, fp_max_x, fp_max_y = z3.Reals('fp_min_x fp_max_x fp_max_y')
    fp_min_y_main, fp_min_y_entry = z3.Reals('fp_min_y_main fp_min_y_entry')
    
    opt.add(fp_min_x == p_west + 5)
    opt.add(fp_max_x == p_east - 5)
    opt.add(fp_max_y == p_north - 25)
    opt.add(fp_min_y_main == p_south_main + 5)
    opt.add(fp_min_y_entry == p_south_entry + 20)
    opt.check()
    m = opt.model()
    
    def get_val(var):
        val = m[var]
        return float(val.as_long()) if z3.is_int_value(val) else float(val.as_fraction())

    z3_left_area = (entry_div - get_val(fp_min_x)) * (get_val(fp_max_y) - get_val(fp_min_y_main))
    z3_right_area = (get_val(fp_max_x) - entry_div) * (get_val(fp_max_y) - get_val(fp_min_y_entry))
    z3_max_area = z3_left_area + z3_right_area

    # =========================================================
    # CAD GEOMETRY VS Z3 MATHEMATICS
    # =========================================================
    ideal_boundary = [
        (0.0, 0.0), (0.0, 76.0), (75.0, 76.0), (75.0, 80.0), (80.0, 80.0),
        (80.0, 0.0), (75.0, 0.0), (75.0, -8.0), (35.0, -8.0), (35.0, 0.0)
    ]
    z3_property_area = calculate_polygon_area(ideal_boundary) 
    dxf_boundary_area = calculate_polygon_area(dxf_boundary_coords)
    
    c1_pass = math.isclose(dxf_boundary_area, z3_property_area, abs_tol=1.0)
    c1_fb = "Property boundaries valid." if c1_pass else f"Coordinate mismatch. Expected Property Area: {z3_property_area}, Extracted: {dxf_boundary_area}"

    c2_pass = True
    c2_fb = "Footprint successfully avoids the tree bounding box."
    if dxf_footprint_coords:
        for (px, py) in dxf_footprint_coords:
            if (75.0 <= px <= 80.0) and (76.0 <= py <= 80.0):
                c2_pass = False
                c2_fb = f"Violation: Coordinate ({px:.2f}, {py:.2f}) intersects the tree zone."
                break

    if not dxf_footprint_coords:
        c3_pass = False
        c3_fb = "No footprint extracted to evaluate."
    else:
        c3_pass = True
        c3_fb = "All footprint coordinates are strictly valid and inside the Z3 legal setbacks."
        for (px, py) in dxf_footprint_coords:
            solver.push()
            solver.add(x == px, y == py)
            solver.add(z3.Not(legal_zone)) 
            if solver.check() == z3.sat:
                c3_pass = False
                c3_fb = f"Violation: Footprint coordinate ({px:.2f}, {py:.2f}) crosses a legal setback line."
                solver.pop()
                break
            solver.pop()

    entry_ys = [p[1] for p in dxf_footprint_coords if p[0] > entry_div + 0.1]
    if entry_ys:
        lowest_entry_y = min(entry_ys)
        z3_expected_entry_y = get_val(fp_min_y_entry)
        c4_pass = lowest_entry_y >= z3_expected_entry_y - 0.1 
        c4_fb = f"Entry logic valid. Z3 derived front setback at Y={z3_expected_entry_y}, CAD lowest point was Y={lowest_entry_y:.2f}." if c4_pass else \
                f"Entry constraint violated. Setback line is Y={z3_expected_entry_y}, CAD encroached to Y={lowest_entry_y:.2f}."
    else:
        c4_pass = False
        c4_fb = f"No footprint geometry found in the entry zone (X > {entry_div}) to verify."

    dxf_footprint_area = calculate_polygon_area(dxf_footprint_coords)
    dxf_coverage_pct = (dxf_footprint_area / z3_property_area * 100) if z3_property_area > 0 else 0.0
    z3_coverage_pct = (z3_max_area / z3_property_area * 100)

    area_matches = math.isclose(dxf_footprint_area, z3_max_area, abs_tol=1.0)
    if area_matches:
        c5_pass = True
        c5_fb = f"PASS. Area is mathematically maximized at {dxf_footprint_area:.2f} sq ft. Coverage correctly verified at {dxf_coverage_pct:.2f}%."
    else:
        c5_pass = False
        c5_fb = (f"FAIL. Footprint is legally valid, but area is NOT maximized.\n"
                 f"   - Expected Max Area (Z3 Calculated): {z3_max_area} | CAD Extracted: {dxf_footprint_area:.2f}\n"
                 f"   - Expected Max Coverage: {z3_coverage_pct:.2f}% | CAD Extracted: {dxf_coverage_pct:.2f}%")
            
    print(f"[Constraint 1: Outer Dimensions] - {'PASS' if c1_pass else 'FAIL'}")
    print(f"Feedback: {c1_fb}\n")
    print(f"[Constraint 2: Tree Preservation] - {'PASS' if c2_pass else 'FAIL'}")
    print(f"Feedback: {c2_fb}\n")
    print(f"[Constraint 3: SBC Building Offsets] - {'PASS' if c3_pass else 'FAIL'}")
    print(f"Feedback: {c3_fb}\n")
    print(f"[Constraint 4: Entry] - {'PASS' if c4_pass else 'FAIL'}")
    print(f"Feedback: {c4_fb}\n")
    print(f"[Constraint 5: Max Area & Coverage] - {'PASS' if c5_pass else 'FAIL'}")
    print(f"Feedback: {c5_fb}\n")
    
    final_status = "PASS" if all([c1_pass, c2_pass, c3_pass, c4_pass, c5_pass]) else "FAIL"
    print(f"FINAL VERIFICATION: [{final_status}]")

if __name__ == "__main__":
    dxf_filename = "layout.dxf"
    boundary_coords, footprint_coords = extract_dxf_data(dxf_filename)
    run_z3_verification(boundary_coords, footprint_coords)
```

- I tried running the entire process multiple times, and the result varied a lot.
- Both agents performed better when data and values were typed out directly — giving images or documents led to worse results.
